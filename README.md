## About Me

Full Stack Developer and Software Engineering student at **UFC (Universidade Federal do Ceará)**, expected graduation in 2026.2. Co-founder and developer at **Miranda Labs**, where I build end-to-end web and mobile solutions — from architecture and API design to front-end delivery — for real clients in production.

- 🔭 Currently building **CLBMCS 2026** (international event management system) and contributing to full stack client projects at Miranda Labs
- 💻 Comfortable across the stack: React/Next.js on the front-end, Node.js/NestJS/ASP.NET Core on the back-end, PostgreSQL for data
- 📚 Continuously studying — recent coursework in Machine Learning, Data Science with Python, and advanced TypeScript
- ⚙️ Most of my active work lives in **private repositories** (client and academic projects), so public contribution graphs only tell part of the story
- 🌱 B.Sc. in Software Engineering — Federal University of Ceará (UFC), Russas Campus
